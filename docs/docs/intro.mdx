# ServoX API

Build, manage, and integrate with the ServoX platform through a modern REST API.

The ServoX API provides endpoints for authentication, resource management, and platform integrations. Whether you're building a frontend application, internal tooling, or third-party integrations, this documentation will help you get up and running quickly.

---

## Quick Start

Get a local development environment running in a few minutes.

1. Start the PostgreSQL database using Docker Compose
2. Install project dependencies with `uv`
3. Configure environment variables
4. Run migrations
5. Start the Django development server

```bash
docker compose up -d
uv sync
python manage.py migrate
python manage.py runserver
```

Continue with the [Getting Started](backend/setup) guide for a complete setup walkthrough.
